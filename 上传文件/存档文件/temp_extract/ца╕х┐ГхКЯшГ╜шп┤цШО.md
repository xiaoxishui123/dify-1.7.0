# 🎬 Sora2 文生视频插件 - 核心功能说明

## 📌 核心特性

### 1. 流式视频生成
- **实时响应**: 采用 SSE (Server-Sent Events) 流式处理
- **进度追踪**: 实时显示 0-100% 生成进度
- **任务管理**: 自动提取和管理任务 ID

### 2. 智能 URL 提取
- **自动识别**: 从流式响应中提取视频播放地址
- **正则匹配**: 精确定位 `src.mp4` 格式的视频文件
- **链接返回**: 直接返回可在线播放的完整 URL

### 3. 多格式支持
- **横屏视频**: 16:9 比例,适合电脑/电视观看
- **竖屏视频**: 9:16 比例,适合手机短视频平台

## 🔑 技术亮点

### API 调用机制
```
用户输入提示词
    ↓
构建 JSON 请求体
    ↓
发送 HTTPS POST 请求
    ↓
接收 SSE 流式响应
    ↓
逐行解析 JSON 数据
    ↓
提取关键信息 (任务ID、进度、URL)
    ↓
返回视频播放链接
```

## 🎯 关键实现细节

### 1. API 端点
```
基础 URL: https://api.302.ai
端点: /v1/chat/completions
参数: ?async=false&callback=https://api.302.ai/async_callback
```

### 2. 请求头
```python
headers = {
    'Accept': 'application/json',
```

### 3. 响应格式
```json
data: {
  "choices": [{

      "role": "assistant"
    }
  }],
  "model": "sora-2",
  "object": "chat.completion.chunk"

```

### 4. 视频 URL 格式

```
https://filesystem.site/gptimage/vg-assets/assets%2Ftask_{id}/...src.mp4?参数
```

```
1. 用户输入
   ├─ 提示词: "一只猫在玩耍"
   └─ 方向: landscape

2. 插件处理
   ├─ 验证 API Key
   ├─ 构建请求
   └─ 发送到 302.AI

3. API 处理
   ├─ 创建任务
   ├─ 排队处理
   └─ 生成视频

4. 流式返回
   ├─ 任务 ID: task_xxx
   ├─ 进度: 0% → 100%
   └─ 状态: 排队中 → 生成中 → 完成

5. 结果提取
   ├─ 解析响应
   ├─ 提取 URL
   └─ 返回链接

6. 用户获取
   └─ 点击链接在线播放
```
