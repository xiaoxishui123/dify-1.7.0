# Sora2 文生视频 Dify 插件使用指南

## 📖 快速开始

### 1. 安装插件

将 `sora2_plugin` 目录复制到 Dify 插件目录中。

### 2. 配置 API Key

1. 访问 [302.AI](https://302.ai) 注册并获取 API Key
2. 在 Dify 插件管理界面配置 API Key (格式: `sk-xxxxxx`)

### 3. 使用插件

在 Dify 工作流中添加"Sora2 文生视频"工具。

## 🎬 核心功能

### 文生视频

根据文本描述生成高质量视频,支持:
- ✅ 详细场景描述
- ✅ 动作和运镜指导
- ✅ 横屏/竖屏切换
- ✅ 实时进度反馈

## 📝 参数说明

### prompt (提示词) - 必填

**格式要求:**
- 详细描述场景、主体、动作
- 包含光线、氛围等细节
- 可指定镜头运动方式

**示例提示词:**

```
场景类:
"一片金色的麦田在微风中摇曳,夕阳西下,天空呈现渐变的橙红色,镜头缓慢推进"

人物类:
"一位穿着白裙的女孩在海边奔跑,长发随风飘扬,镜头跟随并环绕拍摄"

动物类:
"一只橘猫慵懒地躺在窗台上晒太阳,窗外是城市风景,镜头特写猫咪的表情"

抽象类:
"彩色墨水在清水中缓慢扩散,形成梦幻般的图案,微距拍摄,光线柔和"
```

### orientation (视频方向) - 可选

- `landscape` (默认): 横屏 16:9 - 适合电脑、电视观看
- `portrait`: 竖屏 9:16 - 适合手机短视频

## 🚀 生成流程

1. **提交任务** → 2-5秒
2. **排队处理** → 视服务器负载而定
3. **视频生成** → 30-120秒
4. **返回结果** → 可在线播放的视频链接

### 提示词技巧

1. **描述要具体**
   ```
   ❌ "一只狗在玩"
   ✅ "一只金毛犬在绿色草地上追逐红色飞盘,阳光明媚,镜头跟随狗狗奔跑"
   ```

2. **包含视觉细节**
   ```
   ❌ "日出"
   ✅ "清晨的海平面上,太阳缓缓升起,天空从深蓝渐变到金黄,海面波光粼粼"
   ```

3. **指定镜头运动**
   ```
   - "镜头缓慢推进"
   - "环绕拍摄"
   - "从远到近"
   - "俯视拍摄"
   - "第一人称视角"
   ```

### 常见场景模板

**🌅 自然风景**
```
[主体] + [环境细节] + [光线氛围] + [镜头运动]

示例: "壮丽的雪山在晨光中闪耀,山顶云雾缭绕,前景有松树林,镜头从低角度仰拍并缓慢推进"
```

**👤 人物场景**
```
[人物描述] + [动作] + [环境] + [情绪氛围] + [镜头]

示例: "一个小男孩兴奋地在秋天的公园里踢足球,落叶纷飞,阳光温暖,镜头跟随并环绕"
```

**🐾 动物主题**
```
[动物] + [行为] + [环境背景] + [特写细节]

示例: "一只小浣熊在溪边玩水,用小爪子抓水中的鱼,水花四溅,镜头特写浣熊可爱的表情"
```

**🎨 创意抽象**
```
[视觉元素] + [变化过程] + [色彩描述] + [拍摄方式]

示例: "粉色和蓝色的烟雾在黑色背景中交织旋转,形成梦幻图案,高速摄影,光影对比强烈"
```

## ⚠️ 注意事项

### 内容限制
- ❌ 禁止敏感、暴力、不当内容
- ❌ 避免版权保护的品牌、人物
- ✅ 使用通用、合法的描述

### 性能提示
- 视频生成需要时间,请耐心等待
- 网络不稳定可能导致失败,可重试
- 建议使用稳定的网络环境

### 质量优化
- 提示词越详细,效果越好
- 合理使用镜头运动描述
- 注意光线和氛围描述

## 🔧 故障排查

### 问题 1: API Key 错误
**解决方案:**
- 检查 API Key 格式 (应以 `sk-` 开头)
- 确认 API Key 未过期
- 验证账户额度是否充足

### 问题 2: 生成失败
**可能原因:**
1. 提示词包含敏感内容 → 修改描述
2. 服务器繁忙 → 稍后重试
3. 网络问题 → 检查连接

### 问题 3: 无法获取视频
**解决方案:**
- 检查网络连接
- 确认防火墙设置
- 尝试重新生成
