# 一键生成短视频-豆包语音优化版 工作流优化说明

## 📋 优化概述

本次优化针对原始工作流文件进行了全面的功能增强和性能优化，主要解决了以下问题：

### ✅ 已解决的问题

1. **修复开始节点缺失的批量上传素材功能设置**
   - 增加了文件上传配置，支持图片、视频、音频文件
   - 设置了合理的文件数量限制（5个文件）
   - 支持本地文件和远程URL两种上传方式

2. **增强生成功能 - 添加循环生成能力**
   - 文生图分支：添加了`iteration_text2image`循环节点，根据脚本场景数量批量生成图片
   - 文生视频分支：添加了`iteration_text2video`循环节点，根据脚本场景数量批量生成视频
   - 图生视频分支：添加了`iteration_image2video`循环节点，根据上传图片数量批量生成视频

3. **整体分支优化**
   - 简化了边连接逻辑，使用更清晰的命名规范
   - 合并了冗余的处理节点
   - 优化了错误处理机制
   - 提升了整体执行效率

## 🏗️ 工作流架构

### 主要流程
```
开始节点 → 脚本生成 → SRT字幕生成 → 创建草稿 → 提取草稿ID → 生成模式分支
    ↓
[文生图分支] → 循环迭代 → 提示词生成 → 豆包文生图 → 上传OSS → 添加到草稿
[文生视频分支] → 循环迭代 → 提示词生成 → 豆包文生视频 → 上传OSS → 添加到草稿  
[图生视频分支] → 检查图片 → 循环迭代 → SiliconFlow图生视频 → 上传OSS → 添加到草稿
    ↓
添加字幕 → 旁白检查 → 豆包TTS → 添加旁白 → 背景音乐检查 → 添加BGM → 保存草稿 → 生成下载链接 → 完成
```

### 核心优化点

#### 1. 批量上传功能
- **文件类型支持**：图片、视频、音频
- **上传方式**：本地文件、远程URL
- **数量限制**：最多5个文件
- **自动检测**：图生视频模式自动检测是否有上传图片

#### 2. 循环生成机制
- **智能解析**：自动解析脚本中的场景数量
- **批量处理**：根据场景数量循环生成对应素材
- **场景对应**：每个生成的素材都对应特定的场景ID
- **并行优化**：优化了循环处理的性能

#### 3. 豆包TTS优化
- **多音色支持**：甜美女声、磁性男声、活泼女声、沉稳男声
- **情感控制**：自然、开心、悲伤、愤怒
- **速度调节**：慢速、正常、快速
- **高质量合成**：使用豆包最新TTS技术

## 🚀 使用指南

### 输入参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 视频主题 | 文本 | ✅ | 视频内容描述，最多500字符 |
| 生成模式 | 选择 | ✅ | 文生图/文生视频/图生视频 |
| 视频宽度 | 数字 | ✅ | 480-1920像素 |
| 视频高度 | 数字 | ✅ | 360-1080像素 |
| 视频时长 | 数字 | ✅ | 10-300秒 |
| 启用旁白 | 选择 | ✅ | 启用/禁用 |
| 语音类型 | 选择 | ❌ | 豆包TTS音色选择 |
| 语音情感 | 选择 | ❌ | 情感表达方式 |
| 语音速度 | 选择 | ❌ | 播放速度控制 |
| 启用背景音乐 | 选择 | ✅ | 启用/禁用 |
| 背景音乐URL | 文本 | ❌ | BGM文件链接 |
| API基础URL | 文本 | ✅ | 服务API地址 |

### 文件上传说明

- **图生视频模式**：必须上传至少1张参考图片
- **其他模式**：可选择上传参考素材
- **支持格式**：JPG、PNG、MP4、MP3等常见格式
- **文件大小**：建议单个文件不超过100MB

## 🛠️ 故障排除

### 常见问题

1. **图生视频模式提示无图片**
   - 确保已上传至少1张参考图片
   - 检查图片格式是否支持
   - 验证图片文件是否损坏

2. **TTS生成失败**
   - 检查语音参数设置
   - 确认文本内容符合要求
   - 验证API配置是否正确

3. **视频生成超时**
   - 适当减少视频时长
   - 降低视频分辨率
   - 检查网络连接状态
